# AndroidOptimizer

Безопасный Android-оптимизатор на Kotlin + Jetpack Compose.

## Реализовано
- диагностика модели, Android, RAM, хранилища и батареи;
- Usage Access и анализ активности приложений за 7 дней;
- профили: Повседневный, Батарея, Игры, Максимальная производительность;
- Shizuku: обнаружение Binder, запрос разрешения и отслеживание состояния;
- безопасный OptimizationEngine: рекомендации и переходы в штатные настройки Android;
- журнал для будущих изменяющих операций и rollback;
- замеры «До / После» по свободной RAM, хранилищу и уровню батареи без ложного «процента ускорения».

## Правило проекта
AndroidOptimizer не выдаёт закрытие процессов за «очистку RAM», не отключает критические системные пакеты и не применяет неизвестные build.prop-твики. Любое изменяющее действие должно быть явным, проверяемым и иметь способ восстановления исходного состояния.

- защита критических и системных пакетов перед любым действием;
- журналирование открытия настроек выбранного приложения.

## Следующие этапы
1. Экран рекомендаций по конкретным пользовательским приложениям.
2. Белый список безопасных Shizuku-действий с проверкой поддержки на устройстве.
3. Snapshot «до/после».
4. Root-модуль отдельно от обычного режима.


## Privacy & Debloat
Сканер выделяет кандидатов по прозрачным признакам и показывает причины. Совпадение по имени пакета или чувствительным разрешениям не считается доказательством шпионажа. Критические системные компоненты защищены от рекомендаций на отключение.
