# AndroidOptimizer

Android-приложение на Kotlin и Jetpack Compose для проверки памяти, активности приложений и предустановленных пакетов. Android 8.0+.

## Версия 0.3.0

- **Главная:** фактическая занятость хранилища, свободная ОЗУ, заряд батареи, анализ устройства и карточки инструментов.
- **Приложения:** полный доступный список, иконки, поиск по названию/пакету, фильтры «Все / Мои / Системные». Разрешение Usage Access нужно только для статистики, а не для загрузки списка.
- **Privacy:** проверка системных пакетов по OEM-базе и признакам в имени пакета, пояснение каждой находки, фильтры «На проверку / Все системные».
- **Ещё:** разрешения, подключение Shizuku, замеры «до/после» и история переходов в настройки.
- Перечни загружаются вне главного потока, ошибки и пустые результаты отображаются явно. После возвращения из настроек данные обновляются.
- Светлая и тёмная тема, стандартные значки, отдельные экраны вместо одной длинной страницы.

## Что делают кнопки

«Проверить устройство» обновляет показатели и список приложений. «Хранилище» открывает системное управление памятью; «Батарея» — энергосбережение. Нажатие на приложение открывает его страницу Android, где пользователь может управлять доступными для этого пакета разрешениями, остановкой, удалением или отключением.

Приложение не очищает чужие кэши, не завершает процессы автоматически и не отключает системные пакеты самостоятельно. Возможность отключения определяет прошивка Android. История переходов не является подтверждением изменения состояния пакета.

## Конфиденциальность и безопасность

Совпадение с правилом не доказывает шпионаж. OEM-база — предварительная подсказка для ручной проверки; назначение пакетов зависит от прошивки. Неизвестные системные пакеты не объявляются кандидатами на отключение автоматически. Защищённые компоненты помечаются «сохранить» и не получают кнопки действия на экране Privacy.

UsageStats объединяются за выбранный интервал (последние 7 дней); при недоступности статистики список установленных приложений сохраняется. Нулевое время не доказывает отсутствие фоновой активности.

Shizuku устанавливается и запускается отдельно. В приложении есть клиент, защищённый provider, отслеживание подключения и запрос разрешения. Изменение состояния пакетов в этой версии остаётся на системном экране Android даже при подключённом Shizuku.

## Сборка и проверка

Нужны JDK 17, Gradle 8.9 и Android SDK 35:

```sh
gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

В GitHub Actions этот набор запускается на pull request. Артефакт `AndroidOptimizer-debug` содержит APK; `AndroidOptimizer-checks` — отчёты тестов, Android Lint и снимки экранов из Robolectric. APK собирается с отладочной подписью. Если установленная версия подписана другим ключом, Android не разрешит обновить её поверх: удаление старой версии удаляет и её локальную историю.

UI-тесты проверяют переходы на все вкладки, поиск установленного приложения без Usage Access, пустой результат и возврат на главную. Они не заменяют проверку OEM-настроек и живого Shizuku на физическом устройстве.
