# AndroidOptimizer

Android-приложение на Kotlin и Jetpack Compose для проверки памяти, активности приложений и предустановленных пакетов. Android 8.0+.

## Версия 0.5.0

- **Главная:** фактическая занятость хранилища, свободная ОЗУ, заряд батареи, анализ устройства и карточки инструментов.
- **Приложения:** полный доступный список, иконки, поиск по названию/пакету, фильтры «Все / Мои / Системные». Разрешение Usage Access нужно только для статистики, а не для загрузки списка.
- **Приватность:** проверка системных пакетов по OEM-базе и признакам в имени пакета, пояснение каждой находки, фильтры «На проверку / Все системные».
- **Настройки (шестерёнка сверху):** разрешения, подключение Shizuku, замеры «до/после» и история переходов в настройки.
- Перечни загружаются вне главного потока, ошибки и пустые результаты отображаются явно. После возвращения из настроек данные обновляются.
- Чёрная тема, цветные карточки, без дублирующей нижней панели и рекомендаций. Из разделов можно вернуться стрелкой или системной кнопкой «Назад».

## Что делают кнопки

«Проверить устройство» обновляет показатели и список приложений. «Память» показывает свободное и занятое место, открывает системное управление хранилищем и загрузки; «Батарея» — энергосбережение. Нажатие на приложение открывает его страницу Android, где пользователь может управлять доступными для этого пакета разрешениями, остановкой, удалением или отключением.

Приложение не очищает чужие кэши и не завершает процессы автоматически. В разделе «Приватность» можно отключить выбранный пакет через запущенный Shizuku 13+ с разрешением пользователя. Перед действием показывается подтверждение. Используется `pm disable-user --user <текущий пользователь>` без удаления данных; «Включить обратно» выполняет `pm enable`. Фильтр «Отключённые» доступен независимо от рекомендации. Прошивка может запретить действие — ошибка отображается явно.

## Конфиденциальность и безопасность

Совпадение с правилом не доказывает шпионаж. OEM-база — предварительная подсказка для ручной проверки; назначение пакетов зависит от прошивки. Неизвестные системные пакеты не объявляются кандидатами на отключение автоматически. Защищённые компоненты помечаются «сохранить» и не получают кнопки действия на экране Privacy.

UsageStats объединяются за выбранный интервал (последние 7 дней); при недоступности статистики список установленных приложений сохраняется. Нулевое время не доказывает отсутствие фоновой активности.

Shizuku устанавливается и запускается отдельно. В приложении есть клиент, защищённый provider, отслеживание подключения и запрос разрешения. Для изменения пакетов используется отдельный Shizuku UserService. Команды передаются массивом аргументов без оболочки; проверяются пакет, пользователь, код завершения и фактическое состояние после изменения. Защищены ядро системы, AndroidOptimizer, Shizuku, постоянные службы, текущая клавиатура, домашний экран, активные администраторы и службы специальных возможностей. Защита не гарантирует отсутствие зависимостей у любого OEM-пакета. Успешные проверенные изменения записываются в журнал; после разрыва связи нужно обновить список. Реальное отключение на TECNO требует проверки на устройстве, CI проверяет логику и интерфейс.

## Сборка и проверка

Нужны JDK 17, Gradle 8.9 и Android SDK 35:

```sh
gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

В GitHub Actions этот набор запускается на pull request. Артефакт `AndroidOptimizer-debug` содержит APK; `AndroidOptimizer-checks` — отчёты тестов, Android Lint и снимки экранов из Robolectric. APK собирается с отладочной подписью. Если установленная версия подписана другим ключом, Android не разрешит обновить её поверх: удаление старой версии удаляет и её локальную историю.

UI-тесты проверяют переходы на все вкладки, поиск установленного приложения без Usage Access, пустой результат и возврат на главную. Они не заменяют проверку OEM-настроек и живого Shizuku на физическом устройстве.
