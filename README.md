# AndroidOptimizer

Безопасный Android-оптимизатор на Kotlin + Jetpack Compose.

## v0.1
- диагностика модели и версии Android;
- свободная/общая RAM;
- свободное/общее внутреннее хранилище;
- заряд батареи;
- переход к системному разрешению Usage Access;
- основа для no-root, Shizuku/ADB и Root режимов.

## План
1. Анализ установленных приложений и фоновой активности.
2. Профили: Повседневный, Батарея, Производительность.
3. Shizuku/ADB функции с проверкой доступности.
4. Root-модуль как отдельный повышенный режим.
5. Журнал изменений и откат применённых оптимизаций.

> AndroidOptimizer не должен применять сомнительные build.prop-твики или отключать критические системные компоненты без проверки и возможности отката.
