# AndroidOptimizer

Безопасный Android-оптимизатор на Kotlin + Jetpack Compose.

## Реализовано
- диагностика модели, Android, RAM, хранилища и батареи;
- Usage Access через системные настройки;
- анализ активности приложений за последние 7 дней;
- список наиболее активно используемых приложений;
- профили: Повседневный, Батарея, Игры, Максимальная производительность;
- системные приложения помечаются отдельно.

## Безопасность
No-root этап не убивает процессы вслепую и не меняет защищённые настройки. Следующий уровень будет через Shizuku/ADB, а Root — отдельным повышенным режимом с журналом и откатом.

## Roadmap
1. Shizuku: обнаружение сервиса и разрешение.
2. Рекомендации по фоновой активности и настройки конкретного приложения.
3. Проверяемые действия для профилей.
4. Root-модуль с сохранением исходных значений и rollback.
5. Экран «до/после».
